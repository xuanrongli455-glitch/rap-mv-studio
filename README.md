# 🎤 3D 說唱 MV 工作室

一個跑在 iPhone 瀏覽器裡的 **真 3D（WebGL / Three.js）說唱歌曲宣傳視頻生成器**。
填上自己的歌名、藝名、歌詞，上傳自己的歌，按一下「錄製成片」，就會即時渲染出 **9:16 直式**的霓虹賽博風 3D 宣傳片（長度＝你的歌；預設是 SOMBRA《Night Shift》整首 **62.76 秒**），直接存成 MP4 發抖音 / IG Reels / YouTube Shorts。

> 這台機器是 iPhone 上的 DSH：沒有 ffmpeg、沒有 Python、不能編譯原生程式，所以**不是離線渲染 MP4 檔**，而是由瀏覽器用你的 GPU 即時渲染 + 內建錄影器輸出影片。好處是你可以無限次改參數、換歌、重錄，0 成本。

## 一、怎麼開（30 秒）

1. 跟 DSH 說「開工作室」（或叫我啟動），我會在背景跑一個本機伺服器（埠 8788）。
2. 用瀏覽器打開：

   **iPhone（同機）**
   ```
   http://127.0.0.1:8788/
   ```

   **Windows / Mac（同一個 Wi-Fi，手機 DSH App 留在前景別鎖屏）**
   ```
   http://192.168.0.134:8788/
   ```
   > 手機換過 Wi-Fi 或 App 重啟後 IP 可能變，叫我重跑一次伺服器，我會印出新的網址。
   > iOS 會凍結背景 App，所以手機要留在 DSH App 前景（建議插電、關自動鎖定）。

3. 建議先開一次能力自檢頁，確認這台機器能不能錄影片、能錄什麼格式：
   ```
   http://192.168.0.134:8788/selftest.html
   ```

4. 看到黑底 + 霓虹城市 + 右側/底部齒輪面板就成功了。

> **除錯**：任何錯誤（含 WebGL、shader、模組載入）會顯示在畫面底部的紅色橫幅，點一下可複製。
> 手機用 Safari 才會有「儲存到檔案」的下載行為；其他 App 內建瀏覽器可能擋下載。

## 二、怎麼做自己的宣傳片（5 步）

| 步驟 | 動作 |
|---|---|
| 1 | 點右上 **⚙︎** 打開面板，填 **歌名 / 藝名 / 標語 / CTA** |
| 2 | 歌詞欄一行一句（預設 15 句、對應四段人聲），按「套用歌詞」自動均分時間 |
| 3 | **上傳音樂**：選你的 mp3 / m4a / wav。系統會自動偵測 BPM，畫面會跟著重拍跳；**這首歌會被記在這台裝置上，下次打開自動載入**（不上傳、不外流） |
| 4 | 按 **▶ 試看** 確認節奏與歌詞時間點；不滿意就調時間軸、BPM、強度、**文字顏色**（歌詞／歌名可分開選色，按「跟隨主題色」可還原） |
| 5 | 按 **● 錄製成片** → 3 秒倒數 → 跟著跑完整首歌（**不要切到別的 App**）→ 自動下載 |

下載的檔案在 **「檔案」App → 下載項目**。
之後：分享 → 存到「照片」→ 就可以直接上傳抖音 / Reels / Shorts（Mac / PC 的話就是一般 mp4）。

## 三、面板裡每一項在做什麼

- **歌名 / 藝名 / 標語 / CTA**：出現的位置是 3D 粒子字 + 霓虹招牌，改了立即反映。
- **歌詞**：每句會以「粒子聚合成文字 → 句末爆散」的方式出現，時間點由你決定（自動均分，可再手動改 `t0/t1`）。
- **比例**：9:16（直式短影音）、16:9（YouTube）、1:1（IG 貼文）。
- **BPM**：上傳音檔自動偵測；偵測不到就手動填，畫面脈動會對齊。
- **主題色**：霓虹賽博 / 暗黑金屬 / 粉紫蒸氣波 / 街頭塗鴉，4 套配色即時換。
- **強度**：鏡頭推移幅度。**震動**：重拍時鏡頭晃動。**光暈**：bloom 發光程度。**顆粒**：底片顆粒感。
- **場景元素**：城市 / 黑膠 / 麥克風 / 粒子 / 歌詞 / 雨，可以關掉做極簡版。
- **📷 存海報**：把當前畫格存成 PNG，當封面圖或限時動態用。

## 四、分鏡（按片長等比縮放；以下為 20 秒基準）

| 時間 | 畫面 |
|---|---|
| 0.0–2.6s | 鏡頭俯衝進霓虹城市，歌名以 3D 粒子字浮現 |
| 2.6–16.2s | 歌詞一句一句砸進畫面，鏡頭沿街道穿梭，黑膠與麥克風道具掠過 |
| 16.2–18.0s | 藝名大字 slam + 背景爆光 |
| 18.0–20.0s | CTA（OUT NOW）＋淡出 |

時間與文字都寫在 `src/config.js` 的 `defaultConfig`，也可以在面板裡改。

## 五、架構

```
rap-mv/
├── index.html            # 版面、importmap、DOM 骨架
├── server.js             # 零依賴靜態伺服器（127.0.0.1:8788，/vendor/three → node_modules）
├── src/
│   ├── config.js         # ★ 唯一設定來源：歌名、歌詞、配色、時長、分鏡
│   ├── main.js           # 整合層：確定性時間軸 + 播放/錄影狀態機
│   ├── contract.md       # 各模組合約（改架構前先讀）
│   ├── scene/            # 3D：霓虹城市、粒子歌詞、鏡頭運動、bloom
│   ├── audio/            # WebAudio：解碼、播放、頻譜、BPM、提供錄影混音 stream
│   ├── record/           # MediaRecorder：canvas.captureStream → mp4/webm
│   ├── ui/               # 控制面板
│   └── lib/              # 純邏輯：BPM 偵測、節拍追蹤、時間軸（可 node 測試）
├── test/                 # node --test 單元測試
└── scripts/verify.mjs    # 專案自檢
```

**想改預設內容**：編輯 `src/config.js` 的 `defaultConfig`（歌名、歌詞與時間點、配色、時長）。
**想改配色**：編輯 `PALETTES`。
**想改分鏡**：`defaultConfig.lyrics[].t0/t1` 與 `src/lib/timeline.js` 的段位切法。

## 六、注意事項 / 疑難排解

| 狀況 | 原因與解法 |
|---|---|
| 畫面全黑、寫「跑不動 WebGL」 | 關掉「低耗電模式」再重試；iOS 省電時會降 WebGL。或換 Safari。 |
| 按錄製沒反應 | 需要先有一次點擊手勢（iOS 限制）。先按一下畫面再按錄製。 |
| 錄出來的檔案沒聲音 | 沒上傳音檔 → 輸出無聲影片。上傳 mp3/m4a 再錄一次。 |
| 影片卡卡的 | 降 pixelRatio、關掉部分場景元素、把 bloom 調低。在面板裡調。 |
| 錄影中途切 App | 會中斷。錄影期間請留在頁面上，建議開飛航/勿擾。 |
| 選檔時檔案是灰的、點不動 | 那是雲端（iCloud／網盤）還沒下載到本機。先在「檔案」App 把它下載，或長按拷貝到「我的 iPad」，再回來選。選檔框已放寬成什麼都能選。 |
| 每次打開都要重新選歌 | 正常情況下會自動接回來（存在這台裝置的 IndexedDB）。**無痕／私密瀏覽**不給存 → 每次都要重選；想清掉就按「重設」。 |
| 下載沒反應 | 用 Safari；或長按檔案連結「下載連結的檔案」。 |
| 想直接給我檔案 | 把 mp3 放進工作區，或在上傳時選「檔案」App 裡的音樂。 |

**隱私**：全部在你的裝置本機跑，音檔不會上傳到任何伺服器。

## 七、指令

```bash
cd rap-mv
node server.js 8788          # 啟動工作室（背景跑）
node scripts/verify.mjs      # 專案自檢（16 項，--strict 為交付模式）
node scripts/run-tests.mjs   # 單元測試（37 個）
```

> 注意：這個沙盒的 `node --check` 會**執行** ESM、`node --test test/` 不支援目錄參數，
> 所以請用上面兩支腳本，不要直接跑 `node --test`。
